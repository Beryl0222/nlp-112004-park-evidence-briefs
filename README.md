# 生态论证简报中的缺席陈述和补查决定

青砾自然保护区的踏查卡来自几个固定调查季。以下地名、物种和团队为演练所用，代号不与真实位置相连。手记有原始版与会审补交版。区划名录的 parent 有值时表示从属，includes 表示登记的一组覆盖成员。

## 本地资料

全部为 UTF-8 编码的合成业务资料。`data/contract.json` 中的列类型带 `?` 时可以是 JSON null。每组记录的 `id` 在该组中唯一，跨组关系以字段说明和清单的 `links` 为准。文字字段保留来源原句，嵌套对象按表中现有格式记录。

- `data/plots.json`。区划、旧称及调查单元。codes 表示历史中可出现在手记的称呼。
- `data/methods.json`。会审使用的调查方法与可判缺席的适用条件。
- `data/surveys.json`。队长登记的出队元数据。日、方法、路线槽位只描述计划和到场时间，完成情况看手记。
- `data/notes.json`。踏查手记、转引和勘误。引用可能同时在 note 原文与 refs 中记载。loggedAt 是接件时间。
- `data/bookings.json`。当季补查资源和已经确认的派工。每个状态对应队伍的实际占用，状态约定见下文。
- `data/hearing.json`。发布简报实际摘录与专家意见。references 记录当时被引用的手记。

## 使用约定

会审以物种、调查单元、季节为证据适用单位。正观察也要能归到具体适用范围。只有方法卡允许且满足完整观察数量才可以宣布调查条件下未记录，不能宣布该物种不存在。其他材料可以作为待核或局部观察描述。近重复的转引不增加独立调查数量。静听的时段由场次所处当地日出的前后一小时确定，4 月日出按 06:00，5 月按 05:50。
青鸣鸟的这一轮调查在 5 月 31 日结束，苇鳞鱼在 5 月或 10 月都可用，任务同组时按登记的对象数占资源。已派出任务不得自动拆散或改期。资源为同一队的实际窗口，不可拿晚过适用期的窗口代替本期覆盖。会审中可由专家决定取消某次仍有缺口的预约，此时相关缺口仍须保留。

## 读取与检查

使用 Node.js 22.23.4，依赖仅用 Node.js 标准库。资料检查依次读入各组 JSON，检查列类型、组内编号及已登记的组间引用，并列出各组记录数。读取入口为 `tools/materials.mjs`，可单独读取一组记录，或读取整个已登记资料包。

```sh
npm run check-data
npm test
```
